PhraseKit on this iPad

Three one-time steps. After this, PhraseKit opens from its icon like an app and talks only to the Nano on this Wi-Fi.

1. Trust the Nano

The Nano signs its own connection so Safari will allow the microphone. Install its certificate once:

  1. Download certificate — Safari says “profile downloaded”.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → turn on PhraseKit Nano CA.

2. Pair this iPad

Ask for a pairing code (tools/nano.sh pair on the Mac prints one; it lasts 10 minutes).

3. Put it on the Home Screen

Share ⎋ → Add to Home Screen. Then set Settings → Display & Brightness → Auto-Lock to Never while in use, and (optionally) Accessibility → Guided Access to keep a patient inside the app.
